## Перечень автоматизируемых сценариев:

### Позитивные (успешные) сценарии:

**№1. Оплата тура с валидной картой с статусом «APPROVED»**
- Название сценария: Оплата тура с валидной картой.
- Тестовые данные: Валидная карта `4444 4444 4444 4441`, срок действия `08/26`, владелец `IVAN IVANOV`, CVV `999`.
- Шаг: Заполнить форму оплаты валидными данными и нажать кнопку «Продолжить».
- Ожидаемый результат: Появляется всплывающее окно с текстом «Операция одобрена банком», в базе данных создаётся запись со статусом «APPROVED».

**№2. Покупка тура в кредит с успешным одобрением кредита**

- Шаг: Заполнить анкету на кредит, нажать кнопку «Купить в кредит».
- Ожидаемый результат: Появляется уведомление с текстом «Кредит одобрен», в базе данных создаётся запись со статусом «CREDIT_APPROVED».

## Перечень используемых инструментов с обоснованием выбора:
1. Python — высокоуровневый язык программирования, простой и понятный синтаксис, подходит для быстрого написания тестов.
2. Requests — библиотека Python для отправки HTTP-запросов, удобная для взаимодействия с RESTful API.
3. PyTest — фреймворк для модульного и интеграционного тестирования, позволяет писать читабельные и гибкие тесты.
4. Selenium — инструмент для автоматизации браузера, используется для UI-тестирования веб-приложения.
5. Allure — система отчетности, помогает визуализировать результаты тестирования.
6. GitHub Actions — CI/CD решение для автоматического запуска тестов при каждом коммите изменений.

### Перечень и описание возможных рисков при автоматизации:
1. Ошибка в конфигурации баз данных: Если неправильно настроены учетные записи и URL базы данных, приложение не сможет подключиться к ней.
2. Отказ службы платежей: Платежный шлюз может отказать в обслуживании, нарушая процесс прохождения теста.
3. Проблемы с эмулятором: Возможны проблемы с настройкой и работой эмулятора Payments Gateway и Credit Gate.
4. Неправильная обработка исключительных ситуаций: Возможно отсутствие обработки ошибок в коде приложения, приводящее к некорректному поведению в негативных сценариях.
